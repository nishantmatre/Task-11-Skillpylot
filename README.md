# SkillPilots – Testing with JUnit UI Demo

A static front-end recreation of the supplied SkillPilots Career Path screenshot, updated for **Day 18: Testing with JUnit**.

## Run in VS Code
1. Extract `SkillPilots_JUnit_Project.zip`.
2. Open the extracted folder in VS Code.
3. Open `index.html` in a browser, or install the Live Server extension.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Click **Steps** on the JUnit project card to open the implementation instructions.
6. Click the moon icon to toggle dark mode.

## Files
- `index.html` – page layout and JUnit task content
- `style.css` – responsive styling
- `script.js` – popup and theme interactions
- `reference-screenshot.png` – supplied screenshot

**Note:** This is a static HTML/CSS/JavaScript recreation based on the screenshot, not the original SkillPilots website source code. It does not include SkillPilots' private backend, database, login, or live account features.
